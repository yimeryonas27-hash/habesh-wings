# Habesh Wings

Habesh Wings is a flight booking mobile application built with Flutter and Dart, integrated with the Fanos API to retrieve flight information and support flight search and booking workflows.

## Features

- Flight search and selection
- One-way flight booking interface
- Flight information through the Fanos API
- Payment screen interface
- Splash screen and user-friendly navigation
- Cross-platform support with Flutter

## Technologies

- Flutter
- Dart
- Fanos API
- REST API integration

## Getting Started

1. Install Flutter and Dart.
2. Clone this repository.
3. Navigate to the project directory.
4. Install dependencies:

   ```bash
   flutter pub get
   ```

5. Run the application:

   ```bash
   flutter run
   ```

## Project Purpose

This project explores mobile flight booking application development using Flutter and API integration.
